Fills the initializer of a CangJie property each time it is generated by the program, for example, when using the Create Property from Usage intention action.
The template is editable. Along with CangJie expressions and comments, you can also use the predefined variables that will be then expanded into the corresponding values.
Predefined variables will take the following values:
${RETURN_TYPE}   a type of a created property
${PROPERTY_NAME}   name of the created property
${CLASS_NAME}   qualified name of the class where property is created
${SIMPLE_CLASS_NAME}   non-qualified name of the class where property is created
