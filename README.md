# CangJie plugin for the IntelliJ Platform

## 安装和使用

如果您想要立即开始，请在您的IDE中打开`设置 > 插件 > 从磁盘安装`。
要创建项目，请使用 **CangJie** 模板。


## 支持的功能

该插件与从版本2023.2开始的所有基于IntelliJ的IDE兼容，其可用功能集存在以下差异：

|        |   |      
|--------|---|
| 语言支持   | + |
| 代码覆盖  | - |
| 检测重复项 | - |
| 调试器   | + |
| 运行目标  | + |
| 分析器   | - |  
|Valgrind内存检查 | - |
