 新架构设计

  在开始实施之前，让我先向你展示重构后的架构设计：

  ┌─────────────────────────────────────────────────────────────────────┐
  │                          入口层 (Entry)                              │
  │  ┌─────────────────────────────────────────────────────────────┐   │
  │  │  DapDebugProcess                                              │   │
  │  │  - XDebugProcess 实现                                         │   │
  │  │  - 只负责 IDE 集成，不负责初始化流程                            │   │
  │  └─────────────────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────────────────┘
                                     │
                                     ▼
  ┌─────────────────────────────────────────────────────────────────────┐
  │                         会话层 (Session)                             │
  │  ┌─────────────────────────────────────────────────────────────┐   │
  │  │  DebugSessionCoordinator (Project Service)                    │   │
  │  │  - 完整的初始化流程编排                                        │   │
  │  │  - 管理会话生命周期                                            │   │
  │  │  - 资源清理                                                    │   │
  │  └─────────────────────────────────────────────────────────────┘   │
  │                                   │                                   │
  │                                   ▼                                   │
  │  ┌─────────────────────────────────────────────────────────────┐   │
  │  │  ManagedDebugSession                                          │   │
  │  │  - 接收已初始化的连接和服务器                                   │   │
  │  │  - 不再重复创建连接                                            │   │
  │  │  - 提供调试操作 API                                            │   │
  │  └─────────────────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────────────────┘
                                     │
                                     ▼
  ┌─────────────────────────────────────────────────────────────────────┐
  │                        协议层 (Protocol)                             │
  │  ┌─────────────────────────────────────────────────────────────┐   │
  │  │  DapProtocolClient                                            │   │
  │  │  - 封装 DAP 协议操作（不管理连接）                              │   │
  │  │  - 使用已建立的 IDebugProtocolServer                          │   │
  │  │  - 事件订阅与分发                                              │   │
  │  └─────────────────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────────────────┘
                                     │
                                     ▼
  ┌─────────────────────────────────────────────────────────────────────┐
  │                         连接层 (Connection)                          │
  │  ┌─────────────────────────────────────────────────────────────┐   │
  │  │  DapConnection（统一的连接类）                                  │   │
  │  │  - Socket 管理                                                 │   │
  │  │  - 重试与重连逻辑                                              │   │
  │  │  - 健康检查                                                    │   │
  │  │  - 返回 IDebugProtocolServer                                  │   │
  │  └─────────────────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────────────────┘
                                     │
                                     ▼
  ┌─────────────────────────────────────────────────────────────────────┐
  │                         服务器层 (Server)                            │
  │  ┌─────────────────────────────────────────────────────────────┐   │
  │  │  ServerLifecycleManager                                       │   │
  │  │  - 端口分配                                                    │   │
  │  │  - 进程启动                                                    │   │
  │  │  - 就绪检测                                                    │   │
  │  └─────────────────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────────────────┘

  关键变更

  1. 删除冗余类
    - 删除旧的 dap/DapConnection.kt（功能与 AsyncDapConnection 重复）
    - 删除旧的 dap/DapAdapter.kt（职责重新分配）
  2. 新的协议客户端
    - 创建 DapProtocolClient，只负责 DAP 协议操作
    - 不再自己创建连接，使用传入的 IDebugProtocolServer
  3. 简化会话管理
    - ManagedDebugSession 接收已初始化的组件
    - 移除重复的连接逻辑
  4. 统一配置
    - 简化 DebugSessionConfig，移除冗余的 AdapterConfig
