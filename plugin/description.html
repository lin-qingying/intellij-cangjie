About Intellij-cangjie

A plugin that provides comprehensive support for the CangJie language in IntelliJ IDEA.

Main Features

  • CangJie language keyword highlighting
  • Automatic identification of project entrances
  • Quick project startup and configuration
  • Code completion and syntax validation
  • Project templates and scaffolding
  • Integrated debugging tools
  • Custom run configurations
