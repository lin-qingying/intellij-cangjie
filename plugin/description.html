about Intellij-cangjie

1.The plugin provides support for CangJie language

2.For developers who prefer to use IDEA, you only need to install the plugin, you can quickly develop cangjie project.

3.The main features of the plug-in include : cangjie development language keyword highlighting , automatic identification of project entrances , quick start project , etc., more features waiting for you to experience .
