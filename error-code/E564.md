# 错误代码：E564

**错误描述：**
在类体中意外的类声明

**触发场景：**
当 Cangjie 编译器在类的定义体内部发现另一个完整的类声明时，会触发此错误。Cangjie 语言不支持在类内部嵌套定义类。

**示例代码：**

```cangjie
class Outer {
    func method() {
        // ...
    }

    class Inner { // E564 错误：在类体中意外的类声明
        // ...
    }
}
```

**解决方法：**
将嵌套的类声明移到外部，使其成为一个独立的顶级类声明。

**示例代码（修正后）：**

```cangjie
class Outer {
    func method() {
        // ...
    }
}

class Inner { // 修正：将 Inner 类移到 Outer 类外部
    // ...
}
```
