# 错误代码：E727

**错误描述：**
类型参数的数量与类型形参的数量不匹配

**触发场景：**
当使用泛型类型或函数时，提供的类型参数数量与声明的类型形参数量不一致时会触发此错误。常见情况包括：
1. 提供了过多的类型参数
2. 提供的类型参数不足
3. 完全没有提供类型参数

**示例代码：**

```cangjie
// 示例1：提供过多的类型参数
class Box<T> {
    value: T
}

let box: Box<Int, String>    // 错误：Box 只需要一个类型参数，但提供了两个

// 示例2：类型参数不足
class Pair<T, U> {
    first: T
    second: U
}

let pair: Pair<Int>    // 错误：Pair 需要两个类型参数，但只提供了一个
```

**解决方法：**
1. 确保提供正确数量的类型参数：
   ```cangjie
   // 对于单个类型参数
   let box: Box<Int>    // 正确：提供了一个类型参数

   // 对于多个类型参数
   let pair: Pair<Int, String>    // 正确：提供了两个类型参数
   ```

2. 检查泛型类型或函数的声明，确认需要的类型参数数量：
   ```cangjie
   class Box<T> {          // 需要一个类型参数
       value: T
   }

   class Pair<T, U> {      // 需要两个类型参数
       first: T
       second: U
   }
   ```

3. 如果不确定类型参数的数量，可以查看类型的文档或定义
