# 错误代码：E74

**错误描述：**
未声明的类型名称 'T'

**触发场景：**
当 Cangjie 编译器在代码中遇到未声明的类型名称（如 `T`）时，会触发此错误。这通常发生在泛型类型未正确声明或未导入相关包的情况下。

**示例代码：**

```cangjie
func example<T>(x: T) {
    // 使用未声明的类型 T
}
```

**解决方法：**
1. 确保所有使用的类型都已正确声明或导入。
2. 检查泛型类型的使用，确保其符合 Cangjie 语言的语法规则。
3. 如果类型来自外部包，请确保已正确导入该包。
