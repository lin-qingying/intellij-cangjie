# 错误代码：E667

**错误描述：**
类型不匹配：期望的类型与实际提供的类型不一致

**触发场景：**
当变量声明或函数调用中期望的类型与实际提供的类型不一致时会触发此错误。常见情况包括：
1. 变量声明时类型不匹配（如将字符串赋值给整数类型）
2. 函数调用时参数类型不匹配（如传递错误类型的参数）

**示例代码：**

```cangjie
// 示例1：变量声明类型不匹配
let a: Int = ""     // 错误：期望 Int 类型，但提供了字符串类型

// 示例2：函数调用类型不匹配
func example() {
    let str = "123"  // Struct-String 类型
    Cangjie(str)     // 错误：Cangjie 函数期望 Int64 类型参数，但收到了 Struct-String 类型
}
```

**解决方法：**
1. 确保变量声明时赋值的类型与声明的类型一致：
   ```cangjie
   let a: Int = 42    // 正确：Int 类型赋值给 Int 类型变量
   ```

2. 确保函数调用时参数类型正确：
   ```cangjie
   func example() {
       let num: Int64 = 123    // 使用正确的 Int64 类型
       Cangjie(num)            // 正确：提供了 Int64 类型参数
   }
   ```

3. 如果需要类型转换，使用适当的类型转换函数
