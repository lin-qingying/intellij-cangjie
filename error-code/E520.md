# 错误代码 E520

**错误信息**：expected expression or declaration, found ')'

---

## 描述

在编译过程中，编译器期望出现表达式或声明，但实际遇到了一个单独的右括号 `)`，导致语法分析失败。

## 触发场景
- 代码中出现了多余或不匹配的右括号。
- 某些表达式或声明未完整书写，直接以 `)` 结尾。
- 例如：
  ```cangjie
  func test() {
    )
  }
  ```

## 解决方法
- 检查报错位置前后的括号配对情况，确保每个左括号 `(` 都有对应的右括号 `)`。
- 检查表达式或声明是否完整，避免遗漏。
- 修正多余的 `)` 或补全缺失的表达式。
