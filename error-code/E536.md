
**错误代码：** E536

**错误描述：**
期望 ';' 或换行符（<NL>），但遇到了 '..'

**触发场景：**
当在 Cangjie 代码中，语句末尾缺少分号 ';' 或换行符时，且后续出现了非法的 '..' 符号，编译器会报此错误。

**示例代码：**

```cangjie
let a = 1 ..
```

**解决方法：**
1. 检查语句末尾是否缺少分号 ';' 或换行符。
2. 检查是否误用了 '..'，如需使用区间操作符，应保证语法正确。
3. 修改代码为合法语句，例如：

```cangjie
let a = 1;
```
或
```cangjie
let a = 1..10
```
