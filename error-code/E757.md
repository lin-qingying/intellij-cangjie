# 错误代码：E757

**错误描述：**
extend 成员 'toString' 不允许遮蔽 'Struct-String' 的成员

**触发场景：**
当尝试在一个 `extend` 块中为 `Struct-String` 类型定义一个名为 `toString` 的成员时，会触发此错误。这是因为 `Struct-String` 类型已经内置了一个 `toString` 方法，而 Cangjie 语言不允许 `extend` 成员遮蔽（shadow）现有类型的内置成员。

**示例代码：**

```cangjie
extend String {
    func toString() : String { // E757 错误：尝试遮蔽内置的 toString 方法
        return "Custom string representation"
    }
}
```

**解决方法：**
避免在 `extend` 块中定义与目标类型内置成员同名的方法或属性。如果需要提供自定义的字符串表示，可以考虑使用不同的方法名称。

**示例代码（修正后）：**

```cangjie
extend  String {
    func toCustomString() : String { // 修正：使用不同的方法名称
        return "Custom string representation"
    }
}
```
