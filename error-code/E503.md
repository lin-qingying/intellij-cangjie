# 错误代码 E503

**错误信息**：在关键字 'func' 后期望函数名，但遇到 '<EOF>'

---

## 描述

编译器在解析函数声明时，发现 'func' 关键字后没有跟随函数名，且遇到了文件结尾（EOF），说明函数声明不完整。

## 触发场景
- 只写了 'func' 关键字，未写函数名。
- 代码意外中断或遗漏。
- 例如：
  ```cangjie
  func
  ```

## 解决方法
- 检查函数声明，确保 'func' 后有合法的函数名。
- 例如：
  ```cangjie
  func test() {
    // ...
  }
  ```
