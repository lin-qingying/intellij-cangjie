# 错误代码：E592

**错误描述：**
比较运算符不能链式使用

**触发场景：**
当在代码中尝试链式使用比较运算符（如 `a < b < c`）时会触发此错误。在 Cangjie 语言中，比较运算符必须分别使用，并用逻辑运算符连接。

**示例代码：**

```cangjie
func main() {
    let a = 1
    let b = 2
    let c = 3
    
    if (a < b < c) {    // 错误：比较运算符不能链式使用
        println("ordered")
    }
    
    let x = 10
    if (0 <= x <= 100) {    // 错误：不能链式检查范围
        println("in range")
    }
}
```

**解决方法：**
1. 使用逻辑运算符（&&）连接多个比较表达式：
   ```cangjie
   func main() {
       let a = 1
       let b = 2
       let c = 3
       
       if (a < b && b < c) {    // 正确：使用逻辑与运算符连接两个比较
           println("ordered")
       }
   }
   ```

2. 对于范围检查，分别比较上下界：
   ```cangjie
   func main() {
       let x = 10
       if (0 <= x && x <= 100) {    // 正确：分别检查上下界
           println("in range")
       }
   }
   ```

3. 如果需要多个比较，可以使用临时变量存储中间结果：
   ```cangjie
   func main() {
       let a = 1
       let b = 2
       let c = 3
       
       let firstCheck = a < b
       let secondCheck = b < c
       if (firstCheck && secondCheck) {
           println("ordered")
       }
   }
   ```
