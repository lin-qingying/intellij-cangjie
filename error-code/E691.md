**错误代码：** E691

**错误描述：**
与已有声明冲突

**触发场景：**
当在 Cangjie 代码中定义变量、函数、类型或其他标识符时，如果名称与当前作用域内已有的声明重复，编译器会报此错误。

**示例代码：**

```cangjie
let a = 1
let a = 2
```

或

```cangjie
func foo() : Int64 {
    return 1
}

func foo() : Int64 {
    return 2
}
```

**解决方法：**
1. 检查当前作用域内是否已存在同名的变量、函数或类型。
2. 修改新声明的名称，避免与已有声明冲突。
3. 如果是重复定义，保留一个有效声明即可。
