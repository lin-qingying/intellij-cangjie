# 错误代码：E684

**错误描述：**
函数调用缺少必需的参数

**触发场景：**
当调用一个需要参数的函数时，如果没有提供所需的参数，将触发此错误。这通常发生在以下情况：
1. 函数调用时完全没有提供参数
2. 提供的参数数量少于函数声明中要求的参数数量

**示例代码：**

```cangjie
main() :Unit {
    a()  // 错误：调用时缺少 Int 类型参数
}

func a(a: Int) {
    // 函数体
}
```

**解决方法：**
1. 确保在调用函数时提供所有必需的参数
2. 检查函数声明，了解需要提供的参数类型和数量
3. 参考正确的调用方式：
   ```cangjie
   main() :Unit {
       a(42)  // 正确：提供了 Int 类型参数
   }
   
   func a(a: Int) {
       // 函数体
   }
   ```
