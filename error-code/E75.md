# 错误代码：E75

**错误描述：**
使用了未声明的标识符 'bb'

**触发场景：**
当在代码中使用了一个未在当前作用域内声明的变量、函数或其他标识符时会触发此错误。常见情况包括：
1. 使用变量前未声明
2. 变量名拼写错误
3. 标识符不在当前作用域内

**示例代码：**

```cangjie
func example() {
    println(bb)    // 错误：使用未声明的标识符 'bb'
}

func main() {
    let aa = 42    // 声明了 aa
    bb = 10        // 错误：bb 未声明就使用
}
```

**解决方法：**
1. 在使用变量前先声明：
   ```cangjie
   func main() {
       let bb = 10    // 正确：先声明后使用
       println(bb)    // 现在可以使用 bb
   }
   ```

2. 检查变量名拼写是否正确：
   ```cangjie
   func main() {
       let value = 42
       println(value)    // 正确：使用正确的变量名
   }
   ```

3. 确保在正确的作用域中使用变量：
   ```cangjie
   func main() {
       let x = 10
       {
           let y = 20
           println(x)    // 正确：外层作用域的变量可见
           println(y)    // 正确：当前作用域的变量
       }
       // println(y)    // 错误：y 不在这个作用域内
   }
   ```
