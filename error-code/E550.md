# 错误代码：E550

**错误描述：**
期望提供类型参数

**触发场景：**
当使用泛型类型或函数时，没有提供必需的类型参数会触发此错误。常见情况包括：
1. 使用泛型类型时未指定具体类型
2. 调用泛型函数时未提供类型参数
3. 类型参数不完整

**示例代码：**

```cangjie
// 示例1：泛型类型缺少类型参数
let list: List     // 错误：List 是泛型类型，需要指定元素类型

// 示例2：泛型函数调用缺少类型参数
func convert<T, U>(value: T): U {
    // 函数实现
}

func main() {
    convert(42)    // 错误：需要指定类型参数 T 和 U
}
```

**解决方法：**
1. 为泛型类型提供具体类型：
   ```cangjie
   let list: List<Int>     // 正确：指定了 List 的元素类型为 Int
   ```

2. 在泛型函数调用时提供类型参数：
   ```cangjie
   func main() {
       let result = convert<Int, String>(42)    // 正确：指定了类型参数
   }
   ```

3. 让编译器通过类型推断自动确定类型参数（如果可能）：
   ```cangjie
   func identity<T>(value: T): T {
       return value
   }
   
   func main() {
       let x = identity(42)    // 正确：编译器可以推断 T 为 Int
   }
   ```
