# 错误代码 E544

**错误信息**：期望 '(' 或 '<'，但遇到 '<EOF>'

---

## 描述

编译器在解析函数或泛型声明时，期望遇到左括号 '(' 或小于号 '<'，但实际遇到了文件结尾（EOF），说明代码未完整书写。

## 触发场景
- 函数声明未补全参数列表或泛型参数。
- 代码块意外结束。
- 例如：
  ```cangjie
  func test
  ```

## 解决方法
- 检查函数或泛型声明是否完整，补全缺失的括号或参数。
- 例如：
  ```cangjie
  func test() {
    // ...
  }
  ```
