# 错误代码：E760

**错误描述：**
接口 'Interface-ToString' 已被 'Struct-String' 实现，请移除它

**触发场景：**
当尝试让 `Struct-String` 类型实现 `Interface-ToString` 接口时，会触发此错误。这是因为 `Struct-String` 是 Cangjie 语言的内置类型，并且已经隐式地实现了所有必要的内部接口，不允许用户代码显式地让内置类型实现接口。

**示例代码：**

```cangjie
interface Interface-ToString {
    func toString() : String
}

struct String : Interface-ToString { // E760 错误：尝试让内置类型实现接口
    // ...
}
```

**解决方法：**
内置类型（如 `Struct-String`）不需要也不允许显式实现接口。如果需要为内置类型添加功能，应使用 `extend` 关键字。

**示例代码（修正后）：**

```cangjie
interface Interface-ToString {
    func toString() : String
}

// 无需让 Struct-String 实现接口，它已经内置了 toString 方法

// 如果需要为 String 类型添加其他功能，可以使用 extend
extend String {
    func anotherMethod() : Void {
        // ...
    }
}
```
