# 错误代码 E170

**错误信息**：main 的返回类型不是 Int64 或 Unit

---

## 描述

在编译时，编译器要求入口函数 `main` 的返回类型必须为 `Int64` 或 `Unit`。如果返回类型为其他类型，则会触发此错误。

## 触发场景
- `main` 函数被定义为除 `Int64` 或 `Unit` 以外的返回类型。
- 例如：
  ```cangjie
  func main(): String {
    return "hello"
  }
  ```

## 解决方法
- 将 `main` 函数的返回类型修改为 `Int64` 或 `Unit`。
- 例如：
  ```cangjie
  func main(): Int64 {
    return 0
  }
  ```
  或
  ```cangjie
  func main(): Unit {
    // 无需返回值
  }
  ```
