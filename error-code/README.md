# 仓颉（CangJie）语言编译器错误代码首页

本目录用于维护仓颉（CangJie）语言编译器发出的所有错误代码，每个错误代码对应一个独立的 Markdown 文件，详细描述其含义、触发条件及解决方法。

## 目录结构说明
- 每个错误代码以其编号命名为单独的 `.md` 文件，例如：`E001.md`、`E002.md` 等
- 本文件作为错误代码的索引和说明页面
