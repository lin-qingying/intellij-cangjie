**错误代码：** E673

**错误描述：**
标识符已在此处声明

**触发场景：**
当尝试重新声明一个在当前作用域已经存在的标识符（例如变量名、函数名等）时，Cangjie 编译器会报告此错误。这通常与错误代码 E691 (与已有声明冲突) 相关联，E673 更具体地指出了原始声明的位置。

**示例代码：**

```cangjie
func main() : Int64 {
    let count = 10 // 'count' is previously declared here (E673)
    let count = 20 // conflict with the declaration (E691)
    return count
}
```

**解决方法：**
1. 检查错误信息中指出的原始声明位置，确认标识符是否确实已被声明。
2. 如果是无意的重复声明，请为新的声明选择一个不同的名称，以避免命名冲突。
3. 如果打算更新或重新赋值给已有的变量，请确保不要使用 `let` 关键字再次声明它，直接赋值即可 (如果变量是可变的)。
